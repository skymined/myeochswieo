# 며칠쉬어 — 연차 계산기

연차 며칠로 최대 며칠 연속으로 쉴 수 있는지 계산해주는 정적 웹사이트.
빌드 도구 없이 순수 HTML/CSS/JS로만 동작한다 (`index.html`을 그대로 열어도 됨).

- 라이브: https://skymined.github.io/myeochswieo/
- 데이터 최종 확인일: 2026-08-20

## 구조

```
index.html        페이지 구조 + SEO 메타 태그 + 정적 공휴일 표(크롤러용)
style.css         디자인 토큰 · 레이아웃 (라이트/다크 모드 대응)
script.js         연차 최적화 알고리즘 + 렌더링
holidays-data.js  2026·2027년 공휴일 데이터 (단일 소스)
og-card.html      공유 미리보기 이미지(og-image.png) 생성용 소스, 사이트에서 링크되지 않음
robots.txt        Googlebot / Naver Yeti 허용 + sitemap 위치
sitemap.xml       색인용 URL 목록
favicon.svg       파비콘
```

## 데이터 갱신 방법

공휴일 데이터는 **두 곳**에 있다 — 반드시 같이 수정할 것:

1. `holidays-data.js` — 실제 계산 로직이 읽는 데이터
2. `index.html` 안의 "2026년/2027년 공휴일·대체공휴일 전체 목록" 정적 표
   (자바스크립트를 실행하지 않는 크롤러, 특히 네이버 Yeti가 그대로 읽도록
   중복 기재한 것)

새 연도 데이터를 추가할 때 확인할 것:
- 「관공서의 공휴일에 관한 규정」기준 대체공휴일 적용 대상: 3·1절, 광복절,
  개천절, 한글날, 설날연휴, 추석연휴, 어린이날, 부처님오신날, 성탄절
- 설날·추석 연휴는 **일요일과 겹칠 때만** 대체공휴일 발생. 나머지 항목은
  **토요일과 겹쳐도** 발생.
- 현충일, 신정, 근로자의 날, 제헌절은 대체공휴일 적용 대상이 아님.
- 제헌절(7/17)은 2008년부터 공휴일 자체가 아님 — 목록에 넣지 않는다.
- 근로자의 날(5/1)은 관공서 공휴일이 아니라 근로기준법상 유급휴일 —
  `type: "worker"`로 표시하고, 사이트에서 토글로 포함 여부를 선택하게 한다.
- 확정 전이라면 정부 발표(행정안전부)로 한 번 더 대조할 것. 임시공휴일은
  통상 몇 달 전에야 국무회의에서 확정된다.
